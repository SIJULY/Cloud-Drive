# My Cloud Pro Max ☁️

* 一个基于 **Flask + Vue 3** 构建的轻量级、高性能个人私有云盘系统。
* 它不仅仅是一个文件管理器，更集成了**流式传输**、**在线影院**、**极客下载**和**智能资源管理**等 Pro 级功能。

---

* 使用 Docker 一键启动，脚本会自动处理环境依赖和配置。
```bash
bash <(curl -sSL https://raw.githubusercontent.com/SIJULY/Cloud-Drive/main/install.sh)
```

## ✨ 核心特性 (Pro Max Highlights)

### 🚀 极致传输体验
* **极客流式下载 (Stream Download)**: 
    * 小文件 (<2GB) 使用 JS 流式管道传输，**在网页内直接显示实时网速和进度条**，支持选择保存路径 (File System Access API)。
    * 下载完成后自动清理服务器临时文件，零残留。
* **智能降级策略 (Smart Fallback)**:
    * 遇到 **>2GB** 的超大文件或不支持 API 的浏览器，自动无缝切换回**浏览器原生下载**，保证传输稳定性。
    * 利用 Linux Inode 特性，原生下载触发 10 秒后自动清理服务器临时文件，**边下边删**，不占服务器空间。
* **并发队列系统 (Task Queue)**:
    * 内置任务队列，限制最大并发数为 3。
    * **彻底解决卡顿**：无论拖入多少文件，页面操作（切换目录、刷新）永远丝滑流畅，不会被传输任务阻塞。

### 🎬 在线影音中心
* **沉浸式播放器**: 双击 MP4/WebM 等视频文件，直接弹出黑色全屏浮层播放，支持拖拽进度、音量调节。
* **分享页在线播**: 生成的分享链接支持**访客模式**。朋友打开链接不仅能下载，还能直接在网页上在线观看视频，无需下载。

### 🛡️ 安全与交互
* **防误触机制**: 当有上传/下载任务进行时，关闭或刷新网页会弹出浏览器级警告，防止传输中断。
* **全功能交互**: 
    * 全屏拖拽上传。
    * 右键上下文菜单 (下载、分享、移动、复制、重命名、删除)。
    * 双击智能判断 (进入文件夹 vs 播放视频 vs 下载文件)。
* **无感刷新**: 页面切换采用微型顶部加载条，数据加载完成后瞬间渲染，消除白屏等待感。

### ♻️ 完善的文件管理
* **回收站机制**: 支持软删除、一键还原、彻底删除和清空回收站。
* **智能分类**: 自动聚合图片、视频、文档、应用，方便快速查找。
* **分享管理**: 一键生成分享链接，支持查看下载次数和取消分享。创建时可设提取码（PBKDF2 加盐哈希存储，错 5 次锁 5 分钟）、下载次数上限、单链有效期；“我的分享”里可随时修改或清除。**文件夹也能分享**：打开链接能看到目录内容、可进子目录、单个文件下载或一键打包成 zip（5GB 上限，每次打包记 1 次下载）。
* **文件收集（File Drop）**: 工具栏“收集文件”生成一个 `/d/` 链接，别人免登录就能往指定文件夹传文件，看不到已有内容；可选提取码、文件数量上限、有效期；重名自动加序号，永不覆盖。
* **PDF 在线预览**: 双击 PDF 直接在浏览器里看（pdf.js 本地加载，翻页/缩放），分享页打开 PDF 链接也能在线预览。
* **图片缩略图**: 列表和宫格里的图片现在加载服务端生成的 320px 缩略图（按 EXIF 方向摆正，缓存 24 小时），大图浏览不再一张张下原图。
* **照片时间线**: 侧边栏“照片时间线”按 EXIF 拍摄日期（没有则用文件修改时间）按月分组展示，点开大图可左右翻看。
* **深色模式**: 侧边栏底部可切换深浅色，刷新后保持。
* **拖拽移动**: 列表/宫格里直接把文件拖到文件夹上就能移动（多选一起拖也行）。
* **标签与收藏**: 右键菜单或列表里的小星星可收藏（侧边栏“我的收藏”汇总），标签用逗号分隔、搜标签名也能找到；移动/重命名/复制/还原时标签和收藏跟着走，彻底删除才清掉。
* **重复文件检测**: 侧边栏“重复文件”按内容哈希（先按大小分组、只对同大小的算哈希）找出内容完全相同的文件，可逐个删或一键“只留最新”。
* **压缩包在线解压**: 双击 zip/tar/tar.gz 先看里面有什么，再点“解压到这里”（解到同名文件夹，重复解压自动改名）；带 Zip-Slip 防护，`../` 穿越和绝对路径条目会被跳过，解压后超 5GB 或文件超 1 万个会拒绝，加密的 zip 成员解不了会明确告知。
* **快捷键**: Ctrl/⌘+A 全选、Ctrl/⌘+C/X/V 复制剪切粘贴、Del 删除、F2 重命名、Enter 打开、Ctrl/⌘+F 或 / 搜索、Esc 取消选择/关弹窗、? 看快捷键表；右键菜单也补了复制/剪切/粘贴和解压入口。
* **WebDAV**: `https://cloud.sijuly.uk/dav/`，用网盘账号密码登录，macOS Finder、Windows 资源管理器、Cyberduck 等都能直接挂载当本地硬盘用。支持浏览、上传、下载、新建文件夹、移动、复制、删除（进回收站，可还原）、锁定；认证失败 5 次同 IP 锁 5 分钟。侧边栏底部可一键复制地址。
* **文件版本**: 覆盖写文件（上传、编辑保存、WebDAV 覆盖）时，旧版自动存一份，最多留最近 10 个；右键“历史版本”可查看、还原（还原前当前版也会先存一份）、删除单个版本。
* **在线文本编辑**: 双击 txt/md/json/yaml/log 等文本文件（≤2MB）直接在浏览器里改，Markdown 可切预览；保存自动产生一个历史版本。
* **全文搜索**: 搜索框回车后走服务端全文搜索——文件名、标签、正文内容都搜（中文按字搜，“爬山”能搜到“今天去爬山”），带内容片段；索引是 SQLite FTS，文件变了自动重建。
* **离线下载**: 侧边栏“离线下载”，粘贴 http(s) 链接或磁力链接，服务器上的 aria2 帮你下，下好自动放进目标文件夹；支持看进度、取消。需容器里 aria2 正常启动（start.sh 里已接好）。
* **720p HLS 流畅播放**: 点播 mp4/mov/mkv 时自动在服务器上转一份 720p HLS 缓存，边转边播，不用等转完；转码失败或没装 ffmpeg 时自动回落原画直播。转码产物缓存在 shares/hls 里，同一文件只转一次。
* **只读外部挂载**: 容器里挂一个只读目录（如 compose 加 `- /host/path:/mnt/external:ro`），再设 `READONLY_MOUNT_PATH=/mnt/external`，根目录会多出一个“外部只读”文件夹，只能看、只能下，不能传、不能改、不能删。不设则不显示。
* **配额**: 环境变量 `QUOTA_GB`（默认 0=不限），超了上传/解压/离线下载会明确拒绝；侧边栏会显示配额用量。
* **操作记录**: 侧边栏“操作记录”，登录、上传、删除、移动、分享、解压、编辑、还原版本等都会记一条（含时间与 IP），最近 100 条，日志超 5MB 自动只留最后 5000 行。
* **两步验证（TOTP）**: 侧边栏“安全设置”里扫码绑定验证器 App，登录时密码+6 位验证码双重验证；验证器丢了可 SSH 删 `data/shares/totp.json` 并重启容器恢复。

## ⚙️ 部署指南

### 1. 环境要求
* Python 3.8+
* Linux 服务器 (推荐 Ubuntu/Debian/CentOS) - *部分清理特性依赖 Linux Inode 机制*

### 2. 安装依赖
```bash
pip install flask
```

### 3. 项目结构
```bash
my-cloud-drive/
├── app.py              # 核心后端逻辑
├── tasks.py            # (可选) 异步任务处理
├── templates/          # 前端模板
│   ├── index.html      # 主控台 (Vue 3 + Pro Max 逻辑)
│   ├── share.html      # 访客分享页 (Jinja2 渲染)
│   └── login.html      # 登录页
├── storage/            # [自动生成] 文件存储区
├── trash/              # [自动生成] 回收站
└── shares/             # [自动生成] 分享数据
```

### 4. 启动服务

```bash
# 开发模式
python app.py

# 生产环境建议使用 Gunicorn
gunicorn -w 4 -b 0.0.0.0:5000 app:app
```

### 5. 账号配置（必须改，绝不用默认密码上线）

```bash
cp .env.example .env
# 编辑 .env：ADMIN_PASS 改成随机强密码，SECRET_KEY 用 openssl rand -hex 32 生成
# SHARE_EXPIRE_DAYS=30：分享默认 30 天过期，0 = 永不过期
```

一键安装脚本会替你生成随机密码和 SECRET_KEY，写进 `/opt/my-cloud-drive/.env`（权限 600）。

### 📖 使用说明

* 登录: 访问 http://你的IP:5000/login。

* 上传: 直接将文件拖入网页，或点击右上角“上传”按钮。

* 下载:

* 单文件: 双击非视频文件，或右键选择下载。

* 批量: 勾选多个文件 -> 点击“下载”，服务器会自动打包。

* 分享: 选中文件 -> 点击“分享” -> 复制链接发给朋友。

* 播放: 双击视频文件即可在线观看。

### 🔒 安全说明（2026-11-14 修订版已修复）
* 所有用户传来的路径都经过校验，`..`、绝对路径、符号链接穿越都会被拦；`/api/download_result` 只允许下载 storage 内的 `archive_*.zip`。
* 分享 ID 从 6 位 hex 加到 12 位，默认 30 天过期（`SHARE_EXPIRE_DAYS` 可改），过期链接返回 404。
* 未配 `SECRET_KEY` 时每次启动生成临时密钥并警告；登录连续 5 次失败锁 IP 5 分钟；上传上限 50GB，文件名经过清洗。
* 元数据 JSON 用锁 + 原子写，Gunicorn 多进程并发写不再丢数据。

### 📝 注意事项
* 视频格式: 在线播放依赖浏览器解码能力，支持 MP4 (H.264), WebM, Ogg。MKV/AVI 等格式建议下载后观看。

* 临时文件清理: 原生下载模式下，系统会在 10 秒后自动删除服务器上的临时压缩包。请勿在点击下载后 10 秒内立即关闭网页标签，否则可能导致清理请求未发送（虽然这对下载没有影响，只会残留垃圾文件）。
